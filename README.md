# PARORANT（パロラント）

1 人で Bot と戦う、タクティカル FPS のパロディゲームです。
あなたは攻撃側。スパイクを持って敵の守るサイトへ攻め込み、設置して爆発させるか、敵を全滅させればラウンドの勝ちです。**先に 5 ラウンド取ったほうが勝ち**。

> 非公式のファンメイド作品です。実在のゲーム・企業とは関係ありません。

## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11（64bit） |
| グラフィック | DirectX 12 に対応した GPU |
| 入力 | キーボードとマウス |
| 空き容量 | 約 1GB |

## インストール

1. [Releases](../../releases) から `PARORANT-v1.0-Win64.zip` をダウンロードする
2. 好きな場所に展開する（日本語やスペースを含まないフォルダがおすすめ。例：`C:\Games\PARORANT`）
3. `PARORANT.exe` をダブルクリックで起動する

- 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（署名のない exe のため）
- 起動しない場合は、展開したフォルダの `Engine\Extras\Redist\en-us\UEPrereqSetup_x64.exe` を一度実行してから、もう一度起動してください
- アンインストールは、展開したフォルダを削除するだけです（設定のセーブデータは `%LOCALAPPDATA%\PARORANT` に残ります）

## 遊び方

### 試合の流れ
1. タイトル画面で難易度を選び、「プレイ」を押す
2. **購入フェーズ（15 秒）**：**B** で購入画面を開き、武器やアーマーを買う
3. **戦闘（100 秒）**：壁が消えたら出発。A か B のサイトへ向かう
4. サイトの中で **4 を長押し（4 秒）** してスパイクを設置。止まっている間だけ進む
5. 設置から **45 秒** で爆発。それまで敵に解除されないように守る

画面上部の案内（「プラントエリアへ向かえ」など）が、いまやることを教えてくれます。

### 勝ちと負け
| 勝ち | 負け |
|---|---|
| 敵を全滅させる | 設置する前に自分が倒される |
| スパイクが爆発する | 時間切れ（100 秒）までに設置できない |
| | スパイクを解除される |

設置した後なら、自分が倒されてもラウンドは続きます。爆発まで解除されなければ勝ちです。

### お金と武器
- 第 1 ラウンドは 800 クレジット。勝つと +3000、負けても +1900、敵を倒すと 1 体 +200、設置で +300
- 生き残れば、武器とアーマーは次のラウンドに持ち越せます
- 倒した敵の武器は **E** で拾えます（予備弾は 3 マガジン分）

| 武器 | 種類 | 特徴 |
|---|---|---|
| グラシック | ハンドガン | 最初から持っている。弱いが無料 |
| ジェリフ | ハンドガン | 高威力。頭に当てれば一撃も |
| ズペクター | サブマシンガン | 近距離の連射に強い |
| パンダル | ライフル | どの距離でも頼れる主力 |

**撃つときは止まる**のがコツです。走りながら撃つと弾が大きくばらけます。

## 操作

| 操作 | キー |
|---|---|
| 移動 | W A S D |
| 視点 | マウス |
| 射撃 | 左クリック |
| リロード | R |
| ジャンプ | Space |
| しゃがむ | Ctrl |
| 歩く（足音が出ない） | Shift（押している間） |
| 武器の持ち替え | 1 メイン / 2 サブ / 3 ナイフ |
| スパイクの設置 | 4（サイトの中で長押し） |
| 購入画面 | B（購入フェーズ中） |
| 武器を拾う | E |
| ナイフの突き / 眺める | 右クリック / C（ナイフを持っているとき） |
| スコアボード | Tab |
| 設定画面（一時停止） | Esc または P |
| チート（無敵）の切り替え | U |

キーはすべて設定画面で変えられます。

## 難易度

| 難易度 | 敵の数 | 敵の動き | 自分の体力 | ひとこと |
|---|---|---|---|---|
| イージー | 3 | 撃つときは立ち止まる。仲間を助けに来ない | 300 | はじめての人に |
| ノーマル | 3 | 撃つときは立ち止まる。倒れた仲間の方へ集まる | 200 | 慣れてきたら |
| ハード | 3 | 左右に動きながら撃つ | 150 | 撃ち合いの練習に |
| ベリーハード | 5 | 動きながら撃つ。人数も多い | 100 | エイムに自信がある人へ |
| パロラント | 5 | ベリーハードと同じ | 100 | **武器はジェリフだけ**。買えるのはアーマーのみ |

勝てないときは **U キーのチート（無敵）** で、マップや敵の動きを覚えるのもアリです。

## 設定

設定画面（Esc / P）で変えられます。設定は保存され、次に起動したときも残ります。

- マウス感度
- キーの割り当て（ボタンを押してから、割り当てたいキーを押す）
- 難易度
- クロスヘアの「射撃エラー」「移動エラー」：オフにすると、撃ったり動いたりしてもクロスヘアが広がりません（命中のしやすさは変わりません）
