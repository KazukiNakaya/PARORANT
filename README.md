# PARORANT（パロラント）

Bot と戦う、タクティカル FPS のパロディゲームです。舞台は運河の町「PACENT（パセント）」と、南国の海辺の砦「PIND（パインド）」。弱い味方 Bot 2 体と一緒に（なしにもできます）、名前とクセを持つ敵 Bot に挑みます。
あなたは攻撃側。スパイクを持って敵の守るサイトへ攻め込み、設置して爆発させるか、敵を全滅させればラウンドの勝ちです。**先に 5 ラウンド取ったほうが勝ち**。

> 非公式のファンメイド作品です。実在のゲーム・企業とは関係ありません。

| 入力 | キーボードとマウス |
| 空き容量 | 約 1GB |

## インストール

1. [Releases](../../releases) から `PARORANT-v2.1-Win64.zip` をダウンロードする
2. 好きな場所に展開する（日本語やスペースを含まないフォルダがおすすめ。例：`C:\Games\PARORANT`）
3. `PARORANT.exe` をダブルクリックで起動する

- 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（署名のない exe のため）
- 起動しない場合は、展開したフォルダの `Engine\Extras\Redist\en-us\UEPrereqSetup_x64.exe` を一度実行してから、もう一度起動してください
- アンインストールは、展開したフォルダを削除するだけです（設定のセーブデータは `%LOCALAPPDATA%\PARORANT` に残ります）

## 遊び方

### 試合の流れ
1. タイトル画面で難易度と味方 Bot（あり／なし）を選び、「プレイ」を押す。マップは 2 つの中から**ランダム**に決まり、最初にマップの紹介画面が出ます（同じマップが 3 回続くことはありません）
2. **購入フェーズ（15 秒）**：**B** で購入画面を開き、武器やアーマーを買う
3. **戦闘（100 秒）**：壁が消えたら出発。A か B のサイトへ向かう
4. サイトの中で **4 を長押し（4 秒）** してスパイクを設置。止まっている間だけ進む
5. 設置から **45 秒** で爆発。それまで敵に解除されないように守る

画面上部の案内（「プラントエリアへ向かえ」など）が、いまやることを教えてくれます。購入フェーズの壁は透けていて、向こうの通りが見えます。
画面の左上にはマップ全体のミニマップが出ます（上が北、緑の三角が自分の位置と向き、見えている敵は赤い点、味方は水色の点）。
画面上部の残り人数のマークは、左が自分と味方、右が敵です。倒されると暗くなります。敵の体には赤、味方には水色の輪郭線が付きます。

### マップ
マップは「PACENT」と「PIND」の 2 つです。試合ごとにランダムで選ばれます。

#### PACENT（パセント）
雲の上に浮かぶ、運河の町が舞台です。サイトは 2 つあります。
- **A サイト**：屋内の市場。狭くて近距離向きで、2 階の回廊があります
- **B サイト**：運河ぞいの広場。開けていて遠距離向きです
- 町の中央を通る橋は、およそ 45 秒ごとに**跳ね橋として上がります**。鐘が鳴ったら合図（予告は約 3 秒、上がっているのは約 6 秒）。上がっている間は渡れず、向こうも見えません。鐘が鳴っている間は、走る足音が敵に聞こえません。B 側には、いつでも渡れる石橋もあります

#### PIND（パインド）
南国の海辺に建つ、白い壁の砦が舞台です。高低差のない、見通しのよいマップです。
- **A サイト**：石畳の広場
- **B サイト**：木の甲板の広場
- **ミッド**：中央の赤土の通り。A にも B にも抜けられます
- 攻撃側は砂浜と桟橋から出発します。通路の角には、木箱・樽・麻袋・壺などの小物があり、ジャンプで上に乗れます

### 味方 Bot
- 味方 2 体があなたの後ろについて来ます。**とても弱い**ので、撃ち合いの戦力ではなく、先に行かせて敵の位置を探る「おとり」として使ってください
- 味方が敵を見つけると、その敵が少しのあいだ表示され、チャットで場所を知らせます。味方が倒されても、勝ち負けには数えません（**あなたが倒されたらラウンドは負け**）
- 味方に撃っても当たりません（フラッシュは味方にも効きます）
- **Z**：照準の先へ 1 体を走らせて見張らせる（走ると足音が出ます）／**X**：全員を呼び戻す
- 味方はタイトル画面の「味方 Bot：あり／なし」で切り替えます

### 勝ちと負け
| 勝ち | 負け |
|---|---|
| 敵を全滅させる | 設置する前に自分が倒される |
| スパイクが爆発する | 時間切れ（100 秒）までに設置できない |
| | スパイクを解除される |

設置した後なら、自分が倒されてもラウンドは続きます。爆発まで解除されなければ勝ちです。

### お金と武器
- 第 1 ラウンドは 800 クレジット。勝つと +3000、負けても +1900、敵を倒すと 1 体 +200、設置で +300
- 生き残れば、武器とアーマーは次のラウンドに持ち越せます
- 倒した敵の武器は **F** で拾えます（予備弾は 3 マガジン分）

| 武器 | 種類 | 特徴 |
|---|---|---|
| グラシック | ハンドガン | 最初から持っている。弱いが無料 |
| ジェリフ | ハンドガン | 高威力。頭に当てれば一撃も |
| ズペクター | サブマシンガン | 近距離の連射に強い |
| パンダル | ライフル | どの距離でも頼れる主力 |

**撃つときは止まる**のがコツです。走りながら撃つと弾が大きくばらけます。

## 操作

| 操作 | キー |
|---|---|
| 移動 | W A S D |
| 視点 | マウス |
| 射撃 | 左クリック |
| リロード | R |
| ジャンプ | Space |
| しゃがむ | Ctrl |
| 歩く（足音が出ない） | Shift（押している間） |

| スパイクの設置 | 4（サイトの中で長押し） |
| 購入画面 | B（購入フェーズ中） |
| 武器を拾う | F |
| スキル（スタート画面で選んだ 3 つ） | C / E / Q で構える・使う（購入画面で回数を買う） |
| スキルの発動（投げる・置く・展開） | 左クリック（構えているとき） |
| ナイフの突き / 眺める | 右クリック / Y（ナイフを持っているとき） |

| チートの切り替え（無敵・時間停止・弾無限・スキル無限） | U |

キーはすべて設定画面で変えられます。

### 演出
- 敵を続けて倒すと、音が高くなっていきます。全員を倒すと「ACE」
- 勝ったラウンドは、条件が合うと称号（ACE、FLAWLESS、CLUTCH、THRIFTY、JUST IN TIME）が出ます。試合の終わりに、取った数が出ます
- 負けたラウンドは、理由（解除された／時間切れ／倒された）が出ます。倒されたときは、相手の名前・武器・距離と、受けた・与えたダメージが画面の右に出て、撃った位置に印が付きます
- マップごとの環境音（PACENT は運河、PIND は波と海鳥）と、残り 10 秒・設置後の音楽が流れます

## スキル

スタート画面で、セットごとに 1 つ（計 3 つ）選びます。回数は購入フェーズに B キーの購入画面でクレジットを払って買います（ブリンク・フラッシュ・リコンは最大 2 回。ラウンドをまたいで、やられても残ります）。

| キー | スキル | 使い方 |
|---|---|---|
| C | ブリンク | 押すと、押している方向（何も押していなければ前）へ素早く移動 |
| C | フラッシュ | 押して構え、左クリックで投げる。光った瞬間にそちらを向いている敵は 5 秒間見えなくなる（自分も、見ていたら食らう） |
| C | リコン | 押して構え、左クリックで投げる。しばらくして周りの敵が壁越しに赤い菱形で見える |
| E | リコール | 1 回目で足元に目印を置く。もう一度押すと、通ってきた道を走って目印へ戻る（戻る間は無敵で、操作できない）。目印は置いてから **25 秒で消え**、残り秒が表示される（消えても回数は戻らない） |
| E | ヒール | 体力を 1 秒に 10 ずつ、最大まで回復（戦闘中だけ、体力が減っているとき） |
| Q | スモーク | Q で構え、左クリックでアンカーを投げる。置いたアンカーを画面の中央に捉えて **F** を押すと煙が広がる（15 秒）。煙の壁をはさむと敵から見えなくなり、煙の中は見通せる |
| Q | アラームボット | 押して構え、左クリックで足元の少し前に置く。近くに見通しのある敵が来ると知らせ、その敵を 7 秒間遅くする |

構えているときは、同じキーをもう一度押すか、1 / 2 / 3 で持ち替えると解除できます。

## 難易度

| 難易度 | 敵の数 | 敵の動き | 自分の体力 | ひとこと |
|---|---|---|---|---|
| イージー | 3 | 撃つときは立ち止まる。仲間を助けに来ない | 300 | はじめての人に |
| ノーマル | 3 | 撃つときは立ち止まる。倒れた仲間の方へ集まる | 200 | 慣れてきたら |
| ハード | 3 | 左右に動きながら撃つ | 150 | 撃ち合いの練習に |
| ベリーハード | 5 | 動きながら撃つ。人数も多い | 100 | エイムに自信がある人へ |
| パロラント | 5 | ベリーハードと同じ | 100 | **武器はジェリフだけ**。買えるのはアーマーのみ |

### 敵 Bot
- 敵にはそれぞれ名前が付き、チャットで話します（敵の位置などの報告は本当のことが多いので、読んで裏をかけます）。倒した・倒されたはキルログに出ます
- ハード以上では、左右に動く・しゃがむ・大きく飛び出すなど、撃ち合いの動きがいろいろ変わります。リロードを焦ってミスするなど、人間らしい失敗もします（イージーほど多く、難しいほど少ない）
- 敵もスキルを使います。イージーは使わず、ノーマルは 1 ラウンドに 1 回、ハード以上は 2 回まで（スパイクを取り返すときの煙や、飛び出す前の閃光など）

勝てないときは **U キーのチート**（無敵・時間停止・弾無限・スキル無限）で、マップや敵の動きを覚えるのもアリです。

## 設定

設定画面（Esc / P）で変えられます。設定は保存され、次に起動したときも残ります。

- マウス感度
- キーの割り当て（ボタンを押してから、割り当てたいキーを押す）
- 難易度
- チャットを表示（切ると、キルログだけ出ます）
- 音楽と環境音の音量（0〜100%）
- クロスヘアの「射撃エラー」「移動エラー」：オフにすると、撃ったり動いたりしてもクロスヘアが広がりません（命中のしやすさは変わりません）

## 既知の問題

- 敵 Bot の強さは調整中です。感想をいただけるとうれしいです
- 味方 Bot は、階段や段差（A の 2 階、B の高台）、橋が上がっている間は、ついて来る動きが十分に確かめられていません。うまく動かないことがあります
- 鐘や効果音などは仮のもので、音量のバランスは調整中です。聞こえ方が気になったら、設定画面で音量を変えてください
