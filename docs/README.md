## 決定済みの方針

- プレイヤーは **1人・攻撃側固定**
- 敵は **Bot・防衛側**（難易度により 3 体または 5 体。v0.32 で変更）
- **5ラウンド先取**（最短5、最長9ラウンド。v0.32 で 3 ラウンド先取から変更）
- アビリティ（スキル）は **Step 21 で追加予定**（ヒール、スモーク、フラッシュ、ブリンク、アラームボット）
- 新規プロジェクト「PARORANT」として作成
