## 段階1の作業詳細（完了 2026-11-04）

1. `/Game/PARORANT/` のフォルダを作る
2. テンプレートのキャラクターとゲームモードを複製して `BP_PR_Character`、`BP_PR_GameMode` にする
3. 入力アクションを追加（歩き、しゃがみ、リロード、武器切替）
4. 構造体 `S_WeaponData` と `DT_Weapons` を作り、4武器の値を入れる
5. `BP_PR_WeaponBase` を作る（ヒットスキャン、ばらつき、リコイル、連射、リロード）
6. コリジョンチャンネル `Weapon` を追加

8. クロスヘアと弾数だけの仮 HUD を作る
9. 再生して確認、値を調整

## 体力の調整（v0.9, 2026-11-04）

- プレイヤーの体力 100 → 300、購入アーマー ライト 25→75・ヘビー 50→150（Bot 3人分）
- Bot はアーマー常に 50（装備の強さに関係なく）、体力 100 のまま
- ダメージ計算を実機で確認：クラシックの頭 1発で Bot が 体力100/アーマー50 → 体力72/アーマー0。計算どおりで、ヴァンダルなら頭1発・胴4発で倒れる
- 「当たらない」と感じる主な原因は、移動中のばらつき（走り +6°、歩き +1.5°）と連射でのばらつき増加（ヴァンダル 1発ごと +0.4°、最大 4°）と考えられる

## 難易度の調整（v0.10, 2026-11-05）

- Bot を弱く：ReactionTime 0.6→0.9、AimError 2.5→4.0（度）
- プレイヤーが走りながら撃つときのばらつきを +6°→+2.5° に緩和
- 実装メモ：Blueprint の関数の入口ピンが、全体コンパイル時に壊れる問題が出た（武器・スパイク・HoldPoint 型の引数を持つ関数）。
  該当関数を「引数なし＋変数経由」に作り直して解消した（全19 Blueprint がエラーなしでコンパイル通過、PIE で起動・武器装備・Bot 出現を確認）
  - Character: EquipWeapon は NewTmp、ReplaceSlotWeapon は SlotIndex のみ（OldTmp / NewTmp / NearbyWeapon を使用）
  - AIController: RetakeThink は RetakeSpike 変数、CanSeeTarget / EngageSeen は Target 変数を読む
  - GameMode: SpawnBot は SpawnHP / SpawnLoadout 変数を読む
- 今後 Blueprint で関数を足すときは、BP クラス型の引数を避け、変数で渡すこと
- 未確認：実入力でのプレイ（購入→拾う→スロット切替、Bot の見る・撃つ・スパイク解除）。確認は直接呼び出しと起動確認のみ
