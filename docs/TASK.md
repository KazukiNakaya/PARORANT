## Step 10. Bot の装備ロジック【最優先】

問題: 1ラウンド目からヴァンダルを持った Bot が出る。Bot の武器は難易度と配置パターンの装備の強さで固定されている。

- [x] 武器を決めている箇所を調べる（`BP_PR_GameMode` の `SpawnGroup`（引数 `Loadout`）、`DT_DefenseSetups`、`BP_PR_GameInstance.Difficulty`）
- [x] **案A（推奨）**: ラウンドごとの装備テーブルを作る。Bot に所持金は持たせない
  - 例: R1 はクラシック／シェリフ中心、R2 からスペクターが混ざる、R3 以降でヴァンダル解禁
  - 難易度で、上限と混在率を変える
  - 3本先取なので、Bot にエコラウンドが出て一気に崩れる展開は避ける
- [x] 難易度ごとの Bot の武器・アーマーを、上の仕組みに統合する（[04](04_enemy_ai.md) の構想表と実装の食い違いを解消）
- [x] ベリーハード（ハンドガンのみ）との整合を確認する
- [ ] Bot がピストルを持ったときの `GunMesh` の向きを直す。今の値はプレイヤーの右手用。`BP_PR_Bot` の BeginPlay で付け直した後に、Bot 用の相対位置・回転を設定する
- [ ] 確認: ラウンドごとに持ち武器が変わる、難易度で変わる、ピストルの向きが自然

案B（Bot にも所持金を持たせる）は、勝敗が荒れるため採用しない想定。決める前に [09](09_open_questions.md) の Q5 を更新する。

## Step 11. Bot AI の改善

問題: 動かない、寄ってこない、撃ち合い中に棒立ちで、一度見つけるとプリエイムで簡単に倒せる。レレレ撃ちまでは不要。

- [x] 視認後、距離に応じて詰める／一定距離を保つ
- [x] 撃ち合い中のリポジション（左右へのストレイフ、近くの遮蔽物へ移動、撃つ・動くを交互に）
- [x] 見失った後に別の角度から覗き直す（同じ場所に棒立ちで戻らない）
- [x] 非戦闘時の巡回・寄りを増やす（今は Hold が長い）
- [x] 捜索中はゆっくり歩く（今は普通の速さ）
- 改修先: `BP_PR_AIController`（`Think` / `EngageSeen` / `EngageLost` / `HoldThink` / `SearchThink` / `AlertThink`）。`EngageSeen` は今は発射とリロードだけ
- 注意: 関数に BP クラス型の引数を付けない（変数で渡す）。[07](07_tech_design.md) と [08 の v0.10 の項](08_roadmap.md) 参照
