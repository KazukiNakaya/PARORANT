# 06. UI と演出

## HUD（戦闘中）

```
┌───────────────────────────────────────────┐
│          [自分 1]  1:23  [敵 2]          │ ← 上中央：スコアとタイマー
│              ● ● ●  (敵の生存数)            │
│                                           │
│                    ┼                      │ ← クロスヘア（ばらつきで広がる）
│                                           │
│                                           │
│ [♥ 100  🛡 50]              [ヴァンダル 25/75] │ ← 左下：体力とアーマー 右下：武器と弾
│                  [💰 3400]                 │
└───────────────────────────────────────────┘
```

| 要素 | 内容 |
|---|---|
| スコア | 自分の取得ラウンド数 − 敵の取得ラウンド数 |
| タイマー | 残り時間。設置後はスパイクのアイコンに変わる（残り時間は表示しない＝本家と同じ） |
| 敵の生存数 | 3つのアイコン、倒すと消える |
| クロスヘア | 緑の十字。ばらつきに合わせて広がる |
| 体力 / アーマー | 数値 |
| 武器 / 弾 | 武器名、装弾数 / 予備弾 |
| クレジット | 購入フェーズのみ表示 |
| ヒットマーカー | 命中時に一瞬表示。頭なら赤、キル時は大きく |
| キルフィード | 右上に「自分 → 敵（ヘッドショット）」 |
| 設置 / 解除の進捗 | 画面中央下のゲージ |

## 購入画面

- 購入フェーズ中に B で開閉。
- 武器 4種とアーマー 2種を並べ、クリックで購入。買えない物はグレー表示。
- 購入済みの武器を再度クリックで売却（同じ購入フェーズ中のみ全額返金）。

### 実装（段階6）

- `WBP_BuyMenu`（UMG）。画面中央に「購入」パネル、右上にクレジット。ゲームは止まらない（歩きながら買える）。マウスカーソルが出る間は視点を動かせない。
- 各ボタンの表示：買える → `ヴァンダル　2900`、所持中 → `所持中`（押せない）、この購入フェーズに買った物 → `売却 +2900`（押すと返金して元の装備に戻る）、お金が足りない → グレー。
- 同じ枠（メイン／サブ／アーマー）の別の物を買い直すと、先に買った分は自動で返金される。
- 購入フェーズが終わると自動で閉じる。設定画面（P）を開くと購入画面は閉じる。
- HUD：購入フェーズ中だけ画面下に `CREDITS 800    [B] BUY`（黄、キーは設定どおり）。

| 音 | 用途 | 優先度 |
|---|---|---|

| ヒット音、ヘッドショット音 | 命中のフィードバック | 高 |

## 実装（段階4）

試作中は Canvas に直接描く `BP_PR_HUD` で表示している（文字は英語。Canvas の標準フォントが日本語に対応していないため）。

| 位置 | 表示 |
|---|---|
| 上中央 1行目 | `YOU 1 - 0 BOT    ROUND 2` |
| 上中央 2行目 | `ENEMIES 生存 / 開始時`（赤） |
| 上中央 3行目 | 購入中は `BUY PHASE 0:12`（黄）、戦闘中は残り時間 `1:23`、結果表示中は `NEXT ROUND 0:04`、試合後は `NEW MATCH IN 0:09` |
| 画面中央 | ラウンド終了時：`ROUND WIN - ELIMINATION`（緑）／`ROUND LOSS - KILLED`・`ROUND LOSS - TIME UP`（赤）。試合終了時：`VICTORY`／`DEFEAT` |
| 左上 | 操作のヒント（`[P/Esc] Settings` など） |

- 設定画面 `WBP_KeyBinds`（タイトル「設定」）は UMG（日本語表示）。上から説明、マウス感度スライダー（数値は小数2桁）、Bot の強さ（イージー / ノーマル / ハードのボタンと現在値。v0.11）、キー一覧（スクロール）、「初期値に戻す」「閉じる（P / Esc）」。
- ラウンド開始時の大きな「ROUND 2」表示とリザルト画面は段階8で作った（下の「段階8で追加」）。キルフィードは v0.21 で追加（下の「v0.21 で追加」）。

### 段階5で追加

| 表示 | 条件 |
|---|---|
| `HOLD [4] TO PLANT SPIKE` と進捗バー（画面中央の下） | 戦闘中に設置エリアの中にいるとき。`[4]` は現在のキー設定を表示する |
| `SPIKE PLANTED`（赤、点滅） | 設置後。残り時間の数字は出さず、残り10秒で点滅が速くなる |
| `!! DEFUSING !!`（橙） | Bot が解除しているとき（本家の解除音の代わり） |
| `ROUND WIN - DETONATED` / `ROUND LOSS - SPIKE DEFUSED` | 爆発・解除でラウンドが終わったとき |

## スタート画面（マップ決定風の鳥瞰・v0.26・Step 15）

タイトルで「プレイ」を押してマップを読み直したあと、ラウンド1が始まる前に、L_Pind を真上から見せる遷移画面を挟む。

| 項目 | 内容 |
|---|---|
| 流れ | タイトル →（プレイ）→ マップ再読み込み → **スタート画面（約5秒）** → プレイヤー視点へ戻る（0.8秒でブレンド）→ ラウンド1の購入フェーズ。「もう一度」も同じ流れ |
| 実装 | `BP_PR_GameMode` の新しいカスタムイベント `PlayIntro`。`BeginPlay` で `bSkipTitle` が true のとき `StartRound` の代わりに呼ぶ。`PlayIntro` の最後でタイマー（`MatchTick`）を始めて `StartRound` へ進む |
| カメラ | 実行時に `CameraActor` を (0, 0, 7600) に出して真下（pitch -90）を向け、`SetViewTargetWithBlend` で切り替える。画面の上が北（+X＝防衛側）、右が東（+Y＝B サイト）。終わったら `DestroyActor` |
| 入力・HUD | `SetCinematicMode` で、スタート画面の間は移動・視点・HUD を止める |
| ウィジェット | `WBP_MapIntro`（UMG）。上下の黒帯、「マップ決定」「PIND」、「あなたは攻撃側　スパイクを設置せよ」、「A サイト ／ B サイト ／ ミッド　5ラウンド先取」（v0.32 で 3 から変更）、「試合開始まで 5」のカウントダウン（`Tick` で `StartT` からの経過を表示） |
| 調整値 | 表示時間は `PlayIntro` の `Delay`（5秒）と `WBP_MapIntro` の `5 - (T - StartT)`、カメラの高さは `PlayIntro` の MakeTransform |

- 確認（PIE）：`bSkipTitle` を true にして起動し、`BeginPlay` から鳥瞰カメラ（視点が `CameraActor`）→ 約10秒後にプレイヤー視点へ戻り、Bot が出ることを確認した。あわせて `PlayIntro` を直接呼んで、鳥瞰のマップ・黒帯・文字・カウントダウンが出ること、約6秒後にプレイヤー視点へ戻り、Bot が出てラウンドが始まることを確認した。
- 未確認：タイトルの「プレイ」ボタンを実際に押す一連の流れ（`OpenLevel` を挟むため）。Bot の強さ表示やマップ上のサイト名ラベルは入れていない。
- 気づいた点：PIE 中、タイトル画面で「Video memory has been exhausted（約 660MB 超過）」の警告がビューポートに出た。鳥瞰に限った現象ではない。GPU メモリの予算超過（大きなテクスチャなどが原因の可能性）で、実機での確認が必要。
