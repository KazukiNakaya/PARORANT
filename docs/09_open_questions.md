# 09. 検討事項

仕様検討で挙がった項目と、その決定（2026-11-04 確定）。遊んでから見直す前提。

| No | 項目 | 決定 | 備考 |
|---|---|---|---|
| Q1 | 設置後にプレイヤーが死亡したとき | **続行し、Bot が解除できるか次第** | 本家に近く、設置の価値が上がる |
| Q2 | 武器の拾い | **倒した Bot の武器を拾える** | 段階3で Bot が武器を落とす仕組みと合わせて実装 |
| Q3 | 距離減衰 | **無し** | |
| Q4 | ナイフの近接攻撃 | **移動が速くなるだけ** | |
| Q5 | Bot の経済 | **難易度で武器固定** | 2026-11-07 見直し済み（v0.22）：ラウンドと難易度で武器の上限を決める（[04](04_enemy_ai.md) の「Bot の装備ロジック」）。所持金は持たせない |

## 遊んでから調整する値

- 1試合の長さ（ラウンド時間 100秒、移動時間）
- Bot の反応時間と命中率
- 走り・歩きのばらつき
- 経済（勝利 3000 / 敗北 1900）で、2ラウンド目にヴァンダルが買えるかどうか
- Rotate する Bot の人数（1体で簡単すぎないか）
