# 01. コンセプト

## 1行で言うと

**「VALORANT のスイフトプレイを、1人で Bot 相手に5分で遊べるようにしたもの」**

## 名前

**PARORANT（パロラント）** … Parody ＋ VALORANT。

## 目指す体験

| 体験 | 実現する要素 |
|---|---|
| 一発の撃ち合いの緊張感 | ヘッドショットで即死しうるダメージ設計、止まって撃つと当たる精度設計 |
| クリアリングの緊張感 | 敵の位置が毎ラウンド変わる、角待ちする Bot |
| 「設置するか、倒しきるか」の判断 | スパイク設置で勝ちにできる、設置後は Bot が解除に寄ってくる |
| ラウンドを跨いだ駆け引き | 簡略化した経済（買える武器が勝敗で変わる） |
| 短く遊べる | 3本先取、1試合5〜10分 |

## スコープ

### 入れるもの（最小構成）

- 1人用、攻撃側固定、Bot 3体
- 5ラウンド先取の試合進行（v0.32 で 3 から変更）
- 撃った瞬間に当たる射撃（ヒットスキャン）、部位ダメージ、移動による精度低下
- スパイクの設置と解除
- 購入フェーズと簡略化した経済
- 2サイトの小さなマップ（ブロックアウト）

### 後回しにするもの

- アビリティ（スモーク、フラッシュなど）
- エージェント（キャラクター）選択
- 守備側でのプレイ、攻守交代
- 本格的なアート、アニメーション、マップの作り込み

### やらないもの

- オンライン対戦
- ランクやアカウント、課金要素
- 一般公開

## 想定するプレイの流れ

```
タイトル → 試合開始
  ┌─ ラウンド開始（購入フェーズ 15秒）
  │    武器とアーマーを買う
  ├─ 戦闘フェーズ（100秒）
  │    Aかミッド経由でBを攻める → 撃ち合い → 設置
  ├─ 設置後（45秒）
  │    寄ってくる Bot を迎え撃つ
  └─ ラウンド終了 → スコア更新
  （どちらかが5勝するまで繰り返し）
→ リザルト → タイトル / もう一度
```
