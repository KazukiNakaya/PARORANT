# 31. CANAL の紹介画面を「雲の上の浮島」にする（Step 44）

2026-11-16、ユーザーの指示「マップが CANAL になった際、鉛直下向きに見下ろす画面になっていますが、紫色っぽい空の上の、雲に浮かんでいる島、というコンセプトにしたいです。マップの外を、簡単に実装できる範囲で作りこんでほしい。このマップ採用画面でしか出てこないので、張りぼてで良い」（参考画像：VALORANT のアセントの紹介画面、今の CANAL の斜め上からの画像）。

## 1. 方針

- 対象は **L_Canal の紹介画面（マップ決定の画面）だけ**。試合中の見え方、光、空、形、当たり判定、経路、フレームレートは変えない。
- 参考画像は「紫がかった空、雲の海、その上に浮く町」という雰囲気だけを借りる。特定の作品の建物や構図は写さない。CANAL の町（今の建物と場外の建物）をそのまま島に載せる。
- 張りぼてでよい。Meshy などクレジットを使うものは使わない。エンジンの基本形状、既存の素材、必要なら Blender（ヘッドレス）で作る簡単な岩の形だけで作る。

## 2. 仕様

### 2.1 カメラ

- 真上（-90°）をやめ、**斜め上から町全体を見下ろす**向きにする（目安：俯角 35〜45°、町全体と島の縁、その下の雲が入る距離）。`MapInfo` の `IntroCamLoc` / `IntroCamRot` を変えるだけで済ませる。
- 画面左上にマップ名、下にスキル選びの欄が出るので、町は画面の中央〜やや右に来るようにする。
- 屋根：斜めからなら屋根がある方が町らしいので、**紹介画面で屋根を隠すのをやめる**（L_Canal の `IntroHide` の対象から屋根を外す。仕組み `SetIntroHide` は残す）。斜めからの画像で、屋根あり・なしを 1 枚ずつ撮って比べ、屋根ありで通りが全く読めなくても屋根ありを採る（雰囲気を優先）。

### 2.2 紹介画面の間だけ出す物（タグ `IntroOnly`）

`IntroHide` の逆。ふだんは非表示・当たり判定なし・影なしで、紹介画面の間だけ表示する。`BP_PR_GameMode.SetIntroHide(bHide)` の中で、タグ `IntroOnly` のアクタを `SetActorHiddenInGame(not bHide)` する（`IntroHide` と同じ場所で切り替える）。タグが無いマップ（L_Pind）では何もしない。

置く物：

| 物 | 内容 |
|---|---|
| 空の幕 | カメラと島をすっぽり包む大きな球（内向き、光を受けない素材）。上は深い青紫、地平は桃色〜淡い紫のグラデーション。試合中の空（SkyAtmosphere など）は変えず、紹介の間だけこの幕が空を覆う |
| 島の地面の縁 | 場外の建物の外側まで、石畳か土の地面を少し広げて、ふちを不揃いにする（今の地面が場外の建物の下まで届いていれば、縁の岩だけ） |
| 島の下の岩 | 島の下に、下へ向かって細くなる岩の塊（逆さの山）。茶〜灰の岩の色。カメラから見える側だけでよい |
| 雲の海 | 島の下〜周りに、白〜薄紫のやわらかい雲を何層か（光を受けない半透明、縁がぼける素材の板や平たい球）。島のふちに少しかかる雲、遠くの雲 |
| 遠くの小島（任意） | 小さい浮島を 2〜3 個、遠くに。既存の場外の建物の部品を 1〜2 個載せる程度 |

- 既にある運河の水や場外の建物はそのまま使う。運河が島の縁で途切れる所は、岩か雲で隠す。
- 距離の霧（ExponentialHeightFog）が紹介のカメラからの見え方を白くしすぎる場合でも、試合中の霧の設定は変えない。幕や雲の素材の側（光を受けない、霧を受けない設定）で対処する。

### 2.3 色

- 空：上 深い青紫 → 地平 桃色がかった淡い紫。
- 雲：白〜薄紫。影の側は少し濃い紫。
- 町の色（テラコッタの屋根、クリーム色の壁）は今のまま。空の紫と屋根の橙が対比になる。
- 紹介画面の文字（白、アンバー）が読めること。

### 2.4 変えないもの

- 試合中の見え方：`IntroOnly` の物は試合中は非表示で、プレイヤーの視点からは一切見えない。
- L_Canal の形、当たり判定、ナビ、経路、光、露出。L_Pind は §2.5 のカメラと屋根の表示だけを変える。
- 紹介画面のウィジェット（`WBP_MapIntro`）の文字や配置。

### 2.5 PIND の紹介画面のカメラ（追加の指示）

2026-11-16、ユーザーの指示「浮島のコンセプトは CANAL について。PIND は海がモチーフなので浮島にする必要はない」「PIND のマップ採用画面は、このカメラ向きにしてください」（エディタで L_Pind を斜め上から見た画像）。

- PIND は浮島にしない。変えるのは**紹介画面のカメラの位置と向きだけ**（L_Pind の `MapInfo` の `IntroCamLoc` / `IntroCamRot`）。
- 向き：ユーザーの画像に合わせる。攻撃側（木の桟橋のある側）の斜め後ろ上から、町全体を見下ろす。手前に砂浜と桟橋、奥と左に海と沖の濃い青が入る。俯角はおよそ 40°、町はやや斜め（外周の角が手前に来る）に見える。
- 屋根：画像では屋根（珊瑚色）と日よけが見えているので、**PIND でも紹介画面で屋根を隠すのをやめる**（`IntroHide` の対象から外す）。
- 画像と撮った紹介画面を並べて、構図（町の向き、海の入り方、砂浜の広さ）が合うまでカメラを直す。
- PIND の物の配置、形、光は変えない。
