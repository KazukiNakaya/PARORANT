# 03. 戦闘とプレイヤー

## プレイヤー

| 項目 | 値 | 備考 |

### 設定画面（実装済み）

- **P** または **Esc** で設定画面を開く（ゲームは一時停止）。各操作の右のボタンをクリックしてから、割り当てたいキー・マウスボタン・マウスホイール（上／下）を入力する。
- F1 をやめた理由：UE のエディタ／開発ビルドでは F1 が「ワイヤーフレーム表示」のデバッグキーに割り当て済みで、押すと画面がワイヤーフレームになるため（F2＝ライティングなし、F3＝通常表示に戻る）。
- ほかの操作と同じキーを選ぶと、2つの操作のキーが入れ替わる（同じキーが2つの操作に付かない）。
- 「初期値に戻す」で上の表の割り当てに戻る。
- 設定はセーブデータ（スロット `PR_Settings`）に保存され、次回起動時も残る。
- 変えられる操作：前進・後退・左右移動（WASD）、ジャンプ、歩き、しゃがみ、射撃、リロード、メイン／サブ武器、武器を拾う、スパイク設置、テスト用の武器切替。
- ホイールは、キー欄をクリックして選択待ちにしてからホイールを回すと割り当たる（例：ジャンプ＝ホイール下）。選択待ちでないときは一覧のスクロールになる。
- 変えられないもの：視点（マウス）、P／Esc（設定画面）。
- 修飾キー同士の組み合わせ（Shift＋E など）とゲームパッドは割り当てられない。
- エディタで再生中は Esc で再生（PIE）が止まるので、エディタでは P を使う。

### マウス感度（実装済み）

- 設定画面上部のスライダーで 0.10〜3.00（0.05刻み、初期値 1.00）。動かすとすぐ反映され、セーブデータ（スロット `PR_Sens`）に保存される。
- 1.00 はテンプレートの元の感度と同じ。「初期値に戻す」で 1.00 に戻る。

> ナイフは最小構成では「持つと移動が速い」だけでも良い（近接攻撃は後回し可）。

## 射撃方式

- **ヒットスキャン**（撃った瞬間に命中判定）。テンプレートの物理弾は使わない。
- カメラ中心から前方へライントレースし、ばらつき（後述）の分だけ方向をずらす。
- 当たった部位で倍率を決める。
- 部位は当たったコンポーネントのタグ（`Head` / `Body` / `Leg`）で判定する（Bot・的人形は部位ごとの当たり判定コンポーネントを持つ）。

## 精度（ばらつき）

VALORANT らしさの要。「止まって撃てば当たる、走りながらは当たらない」を再現する。

| 状態 | 追加のばらつき（度） |
|---|---|
| 静止 | 0（武器の基本値のみ） |
| 歩き | +1.5 |
| 走り | +2.5 |
| しゃがみ静止 | 基本値 × 0.8 |
| 空中 | +10.0 |

| 武器 | 基本ばらつき | 連射での増加 / 発 | 上限 |
|---|---|---|---|
| クラシック | 0.4 | +0.6 | 3.0 |
| シェリフ | 0.25 | +1.5 | 5.0 |
| スペクター | 0.4 | +0.35 | 3.5 |
| ヴァンダル | 0.25 | +0.4 | 4.0 |

- 撃つのをやめると約0.4秒で基本値に戻る。
- **リコイル（反動）**：連射すると照準が上に跳ね上がる。最初の3〜4発はほぼ真上、以降は左右にブレる（簡易パターン）。
- クロスヘアは現在のばらつきに合わせて広がる。

## ダメージ計算

```
部位ダメージ = 武器の部位別ダメージ
アーマー吸収 = min(アーマー残量, 部位ダメージ × 0.66)
体力ダメージ = 部位ダメージ − アーマー吸収
```

- ヴァンダルの頭（160）は体力100＋ヘビー50でも一撃（160×0.66=105.6 → アーマー50を吸収 → 体力に110）。
- ヴァンダルの胴（40）は Bot（体力100＋アーマー50）を4発で倒す（13.6 → 16.4 → 40 → 40 = 110）。本家と同じ。
- v0.9 で実機確認：クラシックで Bot の頭を撃つと 78 → アーマー50吸収 → 体力 72 になった（計算どおり）。
- 走りながら撃つとばらつきが +2.5°（v0.10 で 6° から緩和。10m 先で約0.4m ずれる）、歩きで +1.5°。止まって撃たないとほぼ当たらない（本家と同じ考え方）。
- プレイヤーも Bot も同じ計算を使う。

## 死亡

- プレイヤー：そのラウンドは観戦（スパイクと Bot を見下ろすカメラ）へ移行。
- Bot：倒れて、持っていた武器をその場に落とす。
- 落ちた武器は E で拾える。拾うと同じスロットの武器と持ち替え、元の武器はその場に落ちる（弾数は落とした時のまま）。

## ナイフ（3キー）
- 1 = メインウェポン、2 = サブ（ハンドガン）、3 = ナイフ。キーは設定画面（DT_KeyBinds `Slot3`）で変更可能。
- ナイフは `DT_Weapons` の行 `Knife`（Slot 3、ダメージ50、連射間隔 約0.6秒、弾数表示なし）。射程は約180cmのトレース（`Fire` 内で Slot==3 のとき距離を切替）。
- メッシュは `Knife_FPS_Animations/FPWeapon/Mesh/SKM_Knife`（`LoadData` で Slot==3 のとき差し替え）。ベリーハードでもナイフは使用可。
- 見た目: 右下にカランビットが映る（アニメーションBPは単体モードに切替、位置は `SpawnWeapon` で Slot==3 のとき (-5,45,15) に配置、`MeshScale` 1.5）。
- PIEで確認済み: 3キー装備、左クリックで攻撃、180cm先のBotにダメージが入る（アーマーで一部軽減）。
- 未対応: 専用の振りアニメ、斬撃SE。

## 武器モデルの差し替え（v0.21, 2026-11-07）

| 武器 | メッシュ | 持ち方（プレイヤー） | 銃声ピッチ |
|---|---|---|---|
| クラシック | `LP_LiteWeapons_JC/Models/SM_Weapon_01` | 通常の腕 `FirstPersonMesh` の `GripPoint` | 1.25 |
| シェリフ | `Weapons_Free/Meshes/SM_pistol_001` | 同上 | 0.85 |
| スペクター | `LP_LiteWeapons_JC/Models/SM_SciFi_Weapons_01` | `RifleArms` の `GunSocket` | 1.3 |
| ヴァンダル | `LP_LiteWeapons_JC/Models/SM_Weapon_02` | 同上 | 0.9 |

- `BP_PR_WeaponBase` に `GunMesh`（StaticMeshComponent、`WeaponMesh` 配下、コリジョンなし・影なし）を追加。BeginPlay で `LoadData` の後に新関数 `ApplyGunVisual` を呼び、`WeaponId` に応じてメッシュ・大きさ・位置・向きを設定し、`WeaponMesh`（スケルタル）のメッシュを空にする。ナイフは対象外（従来どおり）。
- 向きの基準: 既存の銃（`SK_AssaultRifle` / `SK_FPGun`）は +Y が銃口。X 前向きのメッシュ（Weapon_01 / 02 / pistol_001）は Yaw 90 で合わせ、SciFi_01（Y 前向き）は回転なし。
- ピストル（Slot 2）: 片手持ち（ナイフ腕）は違和感があったため取りやめ、通常の腕（`FirstPersonMesh`、`GripPoint`）に戻した。`SpawnWeapon` の Slot 2 は付け替えをせず `SetEquipped` へ進み、`UpdateArms` は Slot 3 のみナイフ腕。`GunMesh` は回転 (0, 70, 0)（銃の右側面が見える向き）。シェリフは大きさ 0.6・位置 (-3, 40, 4)、クラシックは 1.23・(-2.3, 45.7, 8)。VALORANT の画面（銃が画面右下、横幅の約 70〜90%・高さの約 63〜100% を占める）を目安にした。メッシュの大きさが違うため値は違うが、画面上の大きさと位置はそろえた。値は PIE のスクリーンショットで合わせた。
- 手動で調整する場所: `BP_PR_WeaponBase` の関数 `ApplyGunVisual` の、武器ごとの分岐内にある `SetRelativeScale3D` / `SetRelativeRotation` / `SetRelativeLocation` の値。PIE 中は `GunMesh` コンポーネントを直接動かして確認でき、決めた値を書き戻す（PIE を止めると戻る）。位置は Y が銃口方向、Z が上下で、1 動かすと画面上で約 8px。この値はボットにも共通で使われる。
- 銃声: 音源は `FirstPersonTemplateWeaponFire02` の1つだけ。`FirePitch` 変数を追加して `Fire` の PlaySoundAtLocation のピッチに接続し、武器ごとに変えている。別の音にするには音源ファイルが必要。
- 未確認: ボットがピストルを持ったときの向き（プレイヤーの腕に合わせた値なので、ボットの `RightHand` ではずれる見込み）、ボットのスペクター／ヴァンダルの横から見た握り、ピストルの両手持ち（ピストル用アニメが無い）。
- 不要になったもの: `LoadData` の Slot 1 で `SK_AssaultRifle` を設定する処理（`ApplyGunVisual` で上書き）。TastyTony のライフル（Honey Badger）は表示されなくなったため、クレジット表記は不要になった。

## しゃがみの視点移動（v0.31）

- 原因：`Crouch` / `UnCrouch` はカプセル（高さ 96→40）を一瞬で切り替えるため、視点が 56cm 一気に動いていた
- 対応：`BP_PR_Character` に `CrouchAlpha`（0 立ち〜1 しゃがみ）と `UpdateCrouchCam` を追加し、`Tick` の先頭で呼ぶ。`CrouchAlpha` を `FInterpTo_Constant` で毎秒 2（＝0.5 秒で 0↔1）動かし、カメラの相対 Z を `60 + 56 × (目標 − CrouchAlpha)` にする。カプセルが切り替わった瞬間の視点の飛びを打ち消して、地面からの視点の高さが 156→100cm（しゃがみ）に連続して動く。落ち着いたときは元の 60
- 確認（PIE）：`Crouch` / `UnCrouch` 後のカメラ相対 Z が 60 に収束することを記録で確認（しゃがみ後 74.8→62.0→60.0）。実際の見た目（体感）は未確認
- 変えていないもの：当たり判定（カプセル）と移動速度（250 / 675）は瞬時に切り替わる。立ち上がりを天井で止められる場合の扱いは `UnCrouch` 任せ
