# 29. マップの抽選と、PIND の作り込み（南国の海辺）

2026-11-16。ユーザーの指示：

- 既存マップのパインド（`L_Pind`）を作り込む。南国の海風の、明るい感じにしたい（参考として海辺のマップの画像が示された）
- マップは 2 つ（CANAL と PIND）で、ランダムにしたい
- 使いまわせるオブジェクトは使いまわしたい。Meshy のクレジットは余裕があるので、いろいろ作って良い

## 0. 方針

- **PIND の形は変えない。** 壁・遮蔽の位置と大きさ、当たり判定、持ち場、経由点、設置エリア、バリア、ナビメッシュ、経路の長さは今のまま。変えるのは見た目と音だけ。
- **参考は「雰囲気」だけ。** 南国、海、強い日差し、白い壁、砂、ヤシの木、という一般的な題材を使う。特定のゲームのマップの形、建物、目印になる造形、柄は写さない。
- **Meshy は遮蔽に使わない**（2026-11-14 の決定のまま。当たり判定と見た目がずれるため）。Meshy で作るのは、場外の飾りと、道の角・壁ぎわに置く小さな飾り（樽と同じ扱い：簡易コリジョン 1 個、乗れる小さな段差）。
- **使いまわす。** 小物は `Content/PARORANT/Art/Props/` に置き、両方のマップで使う。素材（`MI_Canal_*`）、飾りの置き方（`ArtHost` の ISM、タグ）、スクリプトの作りも CANAL のものを使いまわす。CANAL の角の飾り（いま樽 1 種類）にも、今回作る汎用の小物を足す。

## 1. Step 41：マップの抽選

### 1.1 仕様

- 遊べるマップは `L_Canal` と `L_Pind` の 2 つ。試合を始めるたびに、どちらかを抽選する。
  - タイトルの「プレイ」：抽選したマップを開く。
  - リザルトの「もう一度」：抽選し直す（同じマップとは限らない）。
  - リザルトの「タイトルへ」：今のマップのままタイトルへ戻る（変更なし）。
- 抽選は半々。ただし**同じマップが 3 回続かない**（2 回続いたら、次はもう一方）。
- 一覧と直前の結果は `BP_PR_GameInstance` に持つ。
  - `MapList`（Name の配列。既定 `L_Canal`、`L_Pind`）
  - `LastMap`、`SameMapCount`（保存しない。起動中だけ）
  - `DebugMap`（Name。空でなければ抽選せずそのマップを開く。開発用。保存しない）
  - 関数 `PickMap`（次のマップ名を返し、`LastMap` と `SameMapCount` を更新する）
- スタート画面でマップを選ぶ仕組みは作らない。マップ名は、今までどおり紹介画面（鳥瞰）に出る。
- 起動マップ（`GameDefaultMap`）は `L_Canal` のまま。タイトルの背景は起動したマップ。
- **exe に両方のマップを入れる。** パッケージの `-map` を `/Game/PARORANT/Maps/L_Canal+/Game/PARORANT/Maps/L_Pind` にする（`docs/16_release.md`、`docs/17_build_with_enginewire.md` の手順を直す）。あわせて、プロジェクト設定の「パッケージに含めるマップ」（`DefaultGame.ini` の `+MapsToCook`）に 2 つを書く。

### 1.2 確認

- `PickMap` を 200 回呼んだ結果：両方が出る、3 連続が無い、割合がおおよそ半々。
- PIE で「プレイ」相当と「もう一度」相当を呼び、開いたレベル名をログで確かめる（両方のマップが開くこと、開いた先で試合が始まること）。`DebugMap` で固定できること。
- 保存データを変えない。`bSkipTitle` を false に戻す。

## 2. Step 42：PIND を南国の海辺にする

### 2.1 ねらう絵

昼の強い日差し、濃い青の空、まわりは浅い水色の海と白い砂浜。古い石造りの砦と、白い漆喰の建物が混ざった小さな港。壁は白〜クリーム、差し色は青緑（窓枠・扉）と珊瑚色（日よけ・布）。床は砂と、日に焼けた石畳と、木の桟橋。ヤシの木と南国の植物が、場外と道の角にある。

CANAL（暖かい夕方寄りの石の町）と、ひと目で違うマップだと分かること。

### 2.2 守ること（撃ち合いの公平さ）

- 壁・遮蔽の当たり判定と見た目のずれを作らない。遮蔽の箱への飾りは、表面から 3cm 以内（CANAL の Step 38b と同じ）。
- 敵が背景に溶けない。明るい砂・白い壁の前でも、敵（紺の体＋赤い輪郭線）が見分けられること。床と壁を白飛びさせない（露出は固定のまま）。
- 視線を増やさない・減らさない。飾りに当たり判定を付けるのは、角の小物（乗れる段差）だけ。置く決まりは `docs/26_art_meshy.md` §10 と同じ（持ち場・経由点・設置エリアの縁・バリア・スポーンから離す、通路の残り幅を確保、小物の上から新しい視線ができない）。
- 葉・布などの飾りは、歩ける範囲の頭上 3m より下に出さない（視界をさえぎらない）。ヤシの木の幹は、歩ける範囲の中に置かない（場外か、壁の上・裏）。
- フレーム時間を大きく悪くしない（目安：CANAL と同じ 55 FPS 以上）。

### 2.3 作るもの（Meshy を使わない部分：Step 42a）

CANAL の `docs/tools/map_art_l_canal.py`・`map_light_l_canal.py`・`map_minimap_l_canal.py` を手本に、`map_art_l_pind.py`・`map_light_l_pind.py`・`map_minimap_l_pind.py` を作る（何度実行しても同じ結果。タグ `PindArt`／`PindDeco` で作り直せる）。

| 対象 | 内容 |
|---|---|
| 空と光 | 高い太陽（影は短めで、はっきり）、濃い青の空、薄い霞。色は白っぽい昼光。露出は固定。室内はないので、日なたと日陰の差で立体感を出す |
| 海と砂浜 | マップの外周の外に、浅い水色の海の面（当たり判定なし）と砂浜。壁の外が「崖の上の町」ではなく「海に面した港」に見えるように、外周の一部を低い防波堤・桟橋の見た目にする（**外周の当たり判定はそのまま**。見えない壁で今と同じ範囲に止める） |
| 壁 | 白〜クリームの漆喰。腰の高さに石積みの帯、上の縁に笠石、ところどころに青緑の窓枠・鎧戸・扉、珊瑚色の日よけ。古い砦の部分は砂色の石積み。既存の Fab のパネル（`SM_Wall_01`）と建物は、絵に合わなければ外して、CANAL と同じ「箱＋薄い飾り」に置き換える |
| 床 | 攻撃側は砂と木の桟橋、通路は日に焼けた石畳、サイトは A＝石畳の広場、B＝木の甲板、と場所ごとに床を変えて、いる場所が分かるようにする（当たり判定と高さは変えない） |
| 遮蔽の箱 | A・B・ミッドで見た目を変える（木箱、石の台、積んだ麻袋風の箱、など）。**大きさと位置は変えない**。飾りは 3cm 以内 |
| 設置エリア | 今の枠と文字のまま（色だけ、明るい床でも読める色に） |
| 素材 | まず `MI_Canal_*` を使いまわし、足りない色だけ `MI_Pind_*` を足す（単色。テクスチャは使わない） |
| 音 | 環境音 `AMB_Pind`（波、風、遠くの海鳥。`SourceAudio/` のスクリプトで作る）。`BP_PR_MapInfo` の `AmbSound`／`AmbVolume` に設定。音楽は CANAL と共通 |
| マップ情報 | 表示名は `PIND` のまま。ミニマップを撮り直す。紹介画面のカメラ位置を、海が入る向きに見直す。場所の名前（`BP_AreaName`）が未設定なら、絵に合わせて付ける（例：桟橋、砦の門、灯台下、など） |

### 2.4 Meshy で作る小物（Step 42b）

- モデル：`meshy-t2`（ゲーム用の少ないポリゴン）。1 個 15 クレジット（形 5 ＋ テクスチャ 10）。
- **上限：10 種類・作り直し込みで 200 クレジットまで**（2026-11-14 時点の残高 1,255）。上限を超えそうなら、止めて報告する。
- Blender で整える（大きさ、原点を底面の中央、スムーズ、不要な面の削除）。樽のときの手順（`docs/tools/blender_barrel_small.py`、`docs/26_art_meshy.md` §10）を使いまわす。
- 置き場所は 2 種類。
  - **場外の飾り**（当たり判定なし、歩ける範囲の外）：ヤシの木、小舟、など。
  - **角の小物**（簡易コリジョン 1 個、乗れる小さな段差、樽と同じ決まり）：小箱、麻袋、植木鉢、など。

| ヤシの木（低い・曲がった） | 場外 | PIND |
| 南国の低木・大きな葉の植物 | 場外、壁の上 | PIND |

- 既存の樽（`SM_BarrelSmall`）は PIND にも置く。
- CANAL の角の飾り（12 か所・樽 21 個）は、一部を小箱・麻袋・植木鉢・壺に入れ替えて種類を増やす（位置と当たり判定の大きさは、樽のときと同じ決まりを守る）。

## 4. 実装結果

### Step 41：マップの抽選（2026-11-16）

変えたもの：
